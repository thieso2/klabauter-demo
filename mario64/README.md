# Galecrest Isle — movement playground

An original browser 3D platforming playground. No remote gameplay assets are loaded.

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

Open the URL printed by Vite. Keyboard: WASD/arrows move, Space jumps, Shift runs, drag the mouse to orbit, wheel zooms, R recenters, Escape pauses. Standard gamepads and landscape multitouch work at the same time. Pointer lock is optional and never required.
