# Plan: 2048 clone, three themed prototypes

Source: `docs/shape/2048-1yx820w.md`, `docs/spec/2048-1yx820w.md`.

Three fully independent prototypes (q1: no shared code) means three
naturally independent slices — one per theme. Each ticket implements the
complete game (spec section 3) plus its own art direction, entirely inside
its own folder, with no dependency on the other two.

## Tickets

### t1 — Gothic prototype (`gothic/index.html`)
No dependencies. Implements full game rules; gothic art direction (dark
stone/parchment palette, blackletter-style display font via system/self-hosted
means only, ornate carved-stone/parchment tile treatment, no external font
CDN).

### t2 — Roman prototype (`roman/index.html`)
No dependencies. Implements full game rules; Roman art direction
(marble/gold/laurel palette, inscriptional serif font, column/laurel
decorative chrome, no external font CDN).

### t3 — Modern prototype (`modern/index.html`)
No dependencies. Implements full game rules; modern/minimal art direction
(flat bold palette, clean system sans-serif, subtle shadow/rounded-corner
tile treatment, minimal chrome).

All three tickets can run in parallel — none reads or writes the other's
files, and each verifies solely against `docs/spec/2048-1yx820w.md`
sections 3–5 plus its own acceptance-criteria checklist (spec section 4).
