# Turbo Loop Cup

An original browser 2D top-down kart racer. Pick a racer and complete the desert canyon loop against three AI opponents.

```sh
npm install
npm run dev
npm test
npm run build
```

Open the URL printed by Vite. Keyboard: Arrow keys or WASD steer/accelerate, Left Shift holds a drift for a release boost, Space uses a held item. Losing window focus clears all held input.
